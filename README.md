# ZWAIGZNE 6.2 — The Living Circuit

Standalone browser-based experimental drone synthesizer. Open `index.html` or deploy the folder to GitHub Pages. No build step or package installation is required.

## 6.2 interface rebuild
- Removed inconsistent Roman numeral prefixes from the primary navigation.
- Standardized all eight navigation tabs to equal height and consistent typography.
- Rebuilt FLOW layout so its six organs occupy a predictable, equal-size grid and the inspector is a separate, naturally flowing section below it.
- Kept the existing audio engine, patch format and signal routing intact.
- Improved responsive FLOW layout for tablet landscape and narrow screens.

## Deploy
Upload the contents of this folder to the repository root. Enable GitHub Pages from `main` and `/(root)`.
